February updates - EdgeCDN-X

Bring your own domain

You can now use your own domain on the EdgeCDN-X platform. It is possible to delegate a subzone to the DNS infrastructure and register it as a hostAlias with the service, e.g. cdn.yourservice.com. With this you can hide the underlying infrastructure's details.

CoreDNS Plugin refactor

The coreDNS plugin is now completely refactored and no longer requires 3 different plugins to achieve the same functionality. The plugin source code is present at https://github.com/EdgeCDN-X/edgecdnx-plugin
