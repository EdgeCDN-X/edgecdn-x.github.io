This month, take a closer look at healthcheck history in the EdgeCDN-X location view, and watch DNS-based request routing in action.

EdgeCDN-X provides DNS-based global server load balancing to direct requests to suitable edge locations. Choose from static answers, weighted distribution, primary-and-fallback failover, geolocation and IP-prefix routing, or round-robin selection. Health checks, maintenance state, and active alerts help determine which nodes are eligible, while Kubernetes resources keep routing configuration declarative.
